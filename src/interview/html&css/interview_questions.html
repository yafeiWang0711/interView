13. 请说明 CSS 中 `position` 属性的不同值？

17. 请解释 CSS Grid 布局与 Flexbox 的主要区别？

Grid 是二维布局系统（同时控制行和列），适合整体页面布局；Flexbox 是一维布局系统（行或列），适合组件内部布局。Grid 布局由容器和项目组成，使用 grid-template-columns/rows 定义轨道，而 Flexbox 使用 flex-direction 定义主轴。

20. 请解释 CSS 中的 BFC（块级格式化上下文）及其应用场景？

BFC 是一个独立的渲染区域，内部元素的布局不受外部影响。触发 BFC 的条件包括：根元素、float 不为 none、position 为 absolute/fixed、overflow 不为 visible、display 为 inline-block/table-cell/flex 等。BFC 可用于清除浮动、防止 margin 重叠、包含浮动元素等。

21. 请详细解释 HTML5 的离线存储机制及其应用场景？

HTML5 提供了三种主要离线存储方案，各有不同特性和适用场景：

  • localStorage：持久化存储，容量约5-10MB，无过期时间，页面刷新或浏览器重启后数据保留。适用于保存用户偏好设置、本地缓存数据等。
  • sessionStorage：会话级存储，仅在当前标签页/窗口生命周期内有效，关闭页面即清除。适用于临时表单数据、单页面应用状态管理等。
  • Application Cache（已逐步被 Service Worker 取代）：通过 manifest 文件声明需要缓存的资源，支持离线访问整个应用。适用于创建离线可用的 Web 应用。
  • IndexedDB：高级客户端数据库，支持事务、索引和复杂查询，容量更大。适用于需要在客户端存储大量结构化数据的场景。

最佳实践：敏感数据不应存储在客户端；避免存储大量数据影响性能；使用 try-catch 处理存储限制异常；考虑使用 localStorage/sessionStorage 封装库如 localForage 提升开发体验。

23. 详细解释浏览器的关键渲染路径(CRP)及优化策略？

关键渲染路径(Critical Rendering Path)是浏览器将 HTML、CSS 和 JavaScript 转换为屏幕上像素的过程，直接影响首屏加载时间和用户体验。理解并优化 CRP 是前端性能优化的核心。

关键渲染路径的五个阶段：

  1. 构建 DOM 树：解析 HTML 生成 DOM 节点树，描述内容和结构。HTML 解析会被 JS 执行阻塞。
  2. 构建 CSSOM 树：解析 CSS 生成 CSSOM 树，描述样式规则。CSS 解析会阻塞渲染。
  3. 构建渲染树：结合 DOM 和 CSSOM，仅包含可见元素，计算每个节点的样式。
  4. 布局(Layout)：计算元素几何位置和大小(重排/回流)，受盒模型、尺寸、定位影响。
  5. 绘制(Paint)：填充像素，包括颜色、背景、阴影等视觉属性(重绘)。
  6. 合成(Composite)：将页面分层，分别绘制后合并到屏幕(现代浏览器新增步骤)。

关键优化策略：

  • 减少关键资源体积：minify/压缩代码、移除未使用 CSS、使用现代图片格式
  • 优化关键路径长度：减少 HTTP 请求、内联关键资源、预连接关键域
  • 优先加载关键资源：延迟加载非关键 JS/CSS、预加载关键资源
  • 避免阻塞渲染：CSS 异步加载、JS defer/async、媒体查询适配
  • 优化渲染性能：减少布局偏移(CLS)、批量修改 DOM、使用 will-change 提示

29. 请解释 HTML5 的 Web Storage 与 Cookie 的区别？

Web Storage (localStorage/sessionStorage) 存储容量更大（5-10MB vs 4KB），不随请求发送，仅客户端访问；Cookie 容量小，每次请求都会发送到服务器，可设置过期时间和跨域共享。

calc() 允许在 CSS 中进行数学计算，支持加减乘除运算，可混合不同单位（如 px、%、em）。常用于动态计算尺寸，如宽度、高度、边距等。

31. 请解释 HTML5 的 Canvas 与 SVG 的区别？

Canvas 是基于像素的位图，通过 JavaScript 动态绘制，适合复杂动画和游戏；SVG 是基于矢量的 XML 图形，可直接编辑，适合图标和缩放不变形的图形。Canvas 不支持事件处理器，SVG 支持。

34. 什么是 CSS 伪类和伪元素？请举例说明区别。

伪类 (:) 用于选择元素的特殊状态（如 :hover、:active、:nth-child()）；伪元素 (::) 用于创建不在 DOM 中的虚拟元素（如 ::before、::after、::first-line）。一个选择器可包含多个伪类，但只能有一个伪元素。

36. 请解释 HTML5 的 Web Workers？

Web Workers 允许在后台线程运行 JavaScript，避免阻塞主线程，提升页面响应性。适用于复杂计算、数据处理等耗时操作。主线程与 Worker 通过 postMessage 通信。

self.onmessage = e => { if (e.data.type === 'calculate') { const result = e.data.data * 2; self.postMessage(result); } };
