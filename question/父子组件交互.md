### react 父子组件交互
    1. 父组件向子组件传递数据
        父组件通过props向子组件传递数据
        直接在子组件标签上添加属性即可，属性名就是子组件props的属性名，属性值就是传递的数据
        子组件通过props接收父组件传递的数据，在子组件中通过this.props获取传递的数据
        例如：
        <Child msg="我是父组件的msg" count={count} />
        子组件中：
        函数组件：
        const Child = (props) => {
            const {msg, count} = props;
        }
        类组件：
        const {msg, count} = this.props;
        子组件中可以直接使用props的属性，也可以通过解构赋值的方式获取props的属性
    2. 子组件向父组件传递数据
        通过回调函数的方式实现
        1. 父组件定义一个函数，将函数作为props传递给子组件
        2. 子组件调用该函数，将数据作为参数传递给父组件
        3. 父组件在函数中接收数据，进行处理
    
    3. 父组件调用子组件的方法
        父组件通过ref引用子组件，然后调用子组件的方法
        1. 父组件定义一个ref，用于引用子组件
        2. 子组件通过ref属性将ref传递给子组件
        3. 父组件通过ref引用子组件，然后调用子组件的方法
        例如：
        <Child ref={this.childRef} />
        父组件中：
        this.childRef.current.sayHello();
        子组件中：
        类组件：
        class Child extends Component {
            sayHello() {
                console.log('hello');
