### vue2的响应式原理
   1. 作用：Vue2 采用 Object.defineProperty 实现响应式，核心是对数据对象的属性进行劫持。
   2. 实现流程：
      1. 初始化阶段：
         1. 对 data 选项中的对象进行递归遍历
         2. 对每个属性调用 Object.defineProperty 方法
         3. 为属性添加 getter 和 setter 方法
      2. 依赖收集：
         1. 当组件渲染时，访问数据会触发 getter
         2. getter 会将当前组件的 Watcher（观察者）添加到依赖列表
         3. 一个属性可能被多个组件依赖（多对多关系）
      3. 触发更新：
         1. 当数据被修改时，触发 setter
         2. setter 会通知依赖列表中的所有 Watcher
         3. Watcher 触发组件重新渲染
   3. 优点：
      1. 实现了数据的响应式，当数据发生变化时，会自动触发视图的更新。
      2. 支持细粒度的依赖收集，只有当组件访问到的数据发生变化时，才会触发更新。
   4. 缺点：
      1. 只能劫持对象的属性，不能直接监听数组的变化。
      2. 初始化时需要遍历整个数据对象，性能开销较大。
      3. 不能监听新增属性和删除属性。
    
#### Vue2 响应式的局限性：
    1. 只能监听对象属性的变化，不能直接监听数组的变化。
    2. 无法监听对象新增 / 删除的属性：
        必须使用 Vue.set(obj, key, value) 或 this.$set 才能让新增属性具备响应式
        示例：this.user.age = 20 不会触发更新，需用 this.$set(this.user, 'age', 20)
    3. 无法监听数组的部分操作：
        不能通过索引修改数组元素：this.arr[0] = 1 不会触发更新
        不能直接修改数组长度：this.arr.length = 0 不会触发更新
        需使用重写后的数组方法（push/splice 等）或 Vue.set
    4. 初始化时需要递归遍历所有属性：
        对于层级较深的复杂对象，初始化性能开销较大
    5. 无法在运行时动态劫持新增的嵌套对象属性：
        新增的属性需要通过 Vue.set 或 this.$set 才能具备响应式

### vue3的响应式原理
1. 核心：
    1. Vue3 采用 Proxy 实现响应式，配合 Reflect 提供更完整的劫持能力。
2. 实现流程：
    1. 创建代理：
        使用 new Proxy(target, handler) 创建对象的代理
        handler 包含多种拦截方法（get/set/deleteProperty 等）
        只在访问对象时才会递归处理嵌套对象（懒劫持）
    2. 依赖收集：
        当访问属性时，get 拦截器触发依赖收集
        使用 effect 函数包裹副作用（如组件渲染函数）
        建立属性与副作用的映射关系
    3. 触发更新：
        当修改属性时，set 拦截器触发
        通知所有关联的副作用重新执行
