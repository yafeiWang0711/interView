### 原型
    1. 原型链
        每个对象都有一个原型，原型是一个对象，原型也有自己的原型，以此类推，形成一个原型链。
        例如：
            let obj = {};
            console.log(obj.__proto__); // {}
            console.log(obj.__proto__.__proto__); // null
            console.log(obj.__proto__.__proto__.__proto__); // null
        原型链的尽头是null。

    2. 原型链的查找
        当访问一个对象的属性时，会先在对象本身上查找，如果没有找到，就会沿着原型链查找，直到找到为止。
        例如：
            let obj = {
                a: 1,
                b: 2,
            };
            console.log(obj.a); // 1
            console.log(obj.b); // 2
            console.log(obj.c); // undefined
