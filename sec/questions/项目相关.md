### 智慧机房大屏项目
    1. 分辨率与布局适配问题：大屏的分辨率差异极大，常见的有 1920×1080、3840×2160 等，还可能遇到超宽屏或多屏拼接情况。需保证内容清晰、布局合理，让多图表、多组件在不同分辨率下合理排列，并避免字体模糊或图表变形等状况。
        适配方案：
            1. 响应式布局：利用 CSS 媒体查询，根据不同屏幕尺寸设置不同的布局参数，如宽度、高度、字体大小等。
            2. 流式布局：采用百分比宽度、rem 单位等相对单位，避免固定像素值，使内容在不同屏幕下自动调整。
            3. 弹性布局：利用 flexbox 或 grid 布局，实现组件的自适应调整，避免内容溢出或挤压。
            4. 字体自适应：利用 rem 单位或 viewport 单位，根据屏幕尺寸调整字体大小，避免在不同分辨率下字体模糊。
    2. 大数据处理及性能优化：其常需展示大量实时数据，直接在前端渲染大数据易形成性能瓶颈。另外若有复杂动画，更易加重卡顿现象。需采用数据分页、虚拟滚动等技术，避免一次性加载全部数据导致页面卡顿。
    3. 交互的精准性：需保证鼠标点击、hover 等交互效果在不同缩放比例下精准对应目标组件。若为触控大屏，还需优化触摸事件响应，防止误触，并兼顾不同操作速度与力度的场景。
    4. 实时数据通信稳定性：数据实时更新需可靠通信机制，常借助 WebSocket 或 MQTT 等协议。但在高并发或网络不稳定时，易出现数据同步冲突或丢失状况，且断线重连后要快速恢复数据状态避免展示异常。
### 楼宇消防管理系统项目
    1. 业务与技术的融合：消防维保管理涵盖设备维修、例行月检等诸多复杂业务流程。怎么利用组件化技术精准体现业务逻辑，并保障系统依规范流程运转颇具挑战。
    2. 数据的准确性与实时性：火警等紧急场景容不得数据延迟或错误。需确保烟雾传感器、温度传感器等众多检测设备数据及时、无误更新至系统，多个数据源的数据整合时，易存在格式不一致、数据不完整等问题。
    3. 系统的稳定性和安全性：消防系统关乎生命财产安全，对稳定性要求极高。需避免前端代码异常引发功能中断，并合理处理后端接口故障，防止页面崩溃。同时要保障用户权限管理严谨，加密敏感数据，避免数据泄露致使安全风险。
    4. 应急响应的界面设计：紧急情况需快速调出关键功能与信息，界面需设计成能助力用户迅速定位资源调度、火警定位等核心操作，且避免繁杂布局或交互干扰应急处置。
