### 事件循环
    
    宏任务：宏任务是指在事件循环中执行的任务，例如 setTimeout、setInterval、setImmediate、I/O 操作、UI 渲染等。
    微任务：微任务是指在当前宏任务执行完成后立即执行的任务，例如 Promise、MutationObserver 等。
    区别：
        1.  执行时机：宏任务在事件循环的每个宏任务执行完成后，在当前宏任务的末尾执行一次；而微任务在每个宏任务的开始阶段和结束阶段都执行，而微任务在当前宏任务执行完成后立即执行。
        2.  执行顺序：微任务的执行顺序优先于宏任务。
        3.  执行次数：宏任务可以执行多次，而微任务只能执行一次。
    事件循环的流程：
        1· 执行同步代码（属于当前宏任务的一部分）。
        2· 同步代码执行完毕后，检查微任务队列：
        3. 若有微任务，按顺序全部执行完毕（包括执行微任务过程中新增的微任务）。
        4. 若无微任务，进入下一步。
        5. 执行UI 渲染（可选，浏览器可能会合并多次渲染）。
        6. 从宏任务队列中取一个任务执行，回到步骤 1，重复循环。


    宏任务与微任务的分类
    /**
    * 宏任务(Macrotask)：
    * - setTimeout/setInterval
    * - setImmediate(Node)
    * - requestAnimationFrame
    * - I/O操作
    * - UI渲染
    *
    * 微任务(Microtask)：
    * - Promise.then/catch/finally
    * - process.nextTick(Node，优先级最高)
    * - MutationObserver
    * - queueMicrotask()
    */

    经典执行顺序面试题
    console.log('script start');
    setTimeout(() => {
        console.log('setTimeout');
    }, 0);
    Promise.resolve().then(() => {
        console.log('promise1');
    }).then(() => {
        console.log('promise2');
    });
    console.log('script end');

    执行顺序：
        1. 同步代码：console.log('script start')、console.log('script end')
        2. 微任务：Promise.resolve().then(() => { console.log('promise1') }).then(() => { console.log('promise2') })
        3. 宏任务：setTimeout(() => { console.log('setTimeout') }, 0)

        输出结果：
            script start
            script end
            promise1
            promise2
            setTimeout
