### vue this.$nextTick
    在 Vue.js 中，this.$nextTick() 是一个非常实用的实例方法，用于在 DOM 更新完成后执行回调函数。它解决了 Vue 数据驱动更新 DOM 时的异步问题。
    this.$nextTick(callback) 会将回调函数延迟到 DOM 更新完成后执行。它保证了回调函数中的代码可以操作到最新的 DOM 元素。
    1. 作用：在下次 DOM 更新循环结束之后执行延迟回调。在修改数据之后立即使用这个方法，获取更新后的 DOM。
    2. 应用场景：当你修改了数据，想基于更新后的 DOM 进行某些操作时，使用 this.$nextTick()。

    Vue 内部维护了一个更新队列，当数据变化时，会将需要更新的组件标记为 “脏组件” 并加入队列。在下一个事件循环中，Vue 会遍历队列，执行组件的更新逻辑（重新渲染 DOM），之后触发 $nextTick() 中的回调函数。
    这个过程利用了 JavaScript 的事件循环机制，$nextTick() 的回调会被添加到微任务队列中，确保在 DOM 更新后执行。
    3. 注意事项：
        1. $nextTick() 是异步的，回调函数会在下次事件循环中执行。
        2. 避免在循环中使用 $nextTick()，因为它会导致性能问题。
        3. 避免在 $nextTick() 中修改数据，因为它会导致无限循环。
