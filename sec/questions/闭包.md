### 闭包
    闭包是指在一个函数内部定义的函数，内部函数可以访问外部函数的变量和参数，即使外部函数已经执行完毕。
    闭包的作用是保护变量不被销毁，同时可以实现变量的私有化。
    闭包的实现原理
        闭包的实现原理是利用了 JavaScript 的作用域链。
        作用域链是指在函数执行时，会创建一个作用域链，作用域链是一个数组，数组的每个元素都是一个对象，对象是变量和函数的集合。
        作用域链的作用是查找变量和函数。
        当函数执行时，会创建一个作用域链，作用域链的第一个元素是当前函数的作用域，第二个元素是外部函数的作用域，以此类推。
        当函数执行时，会根据作用域链查找变量和函数。
        闭包的实现原理是利用了作用域链的特性，当内部函数访问外部函数的变量和参数时，会根据作用域链查找变量和参数。
    
    使用闭包的时候会在内存中占用更多的空间，因为闭包会保留外部函数的变量和参数，即使外部函数已经执行完毕。
    闭包的使用场景
        1. 函数作为参数传递
        2. 函数作为返回值
        3. 立即执行函数
        4. 模块化

    闭包解决了什么问题
        1. 保护变量不被销毁
        2. 实现变量的私有化
        3. 实现柯理化函数
        4. 实现事件委托
        5. 实现模块模式

    示例：
        function outer() {
            let a = 1;
            function inner() {
                console.log(a);
            }
            return inner;
        }
        let inner = outer();
        inner(); // 1
        
        inner(); // 1
        a = 2;
            当我们调用 inner 函数时，会打印出 a 的值。
            当我们修改 a 的值时，inner 函数仍然可以访问到最新的 a 的值。
            这是因为 inner 函数形成了一个闭包，闭包会保留外部函数的变量和参数，即使外部函数已经执行完毕。
            闭包的作用是保护变量不被销毁，同时可以实现变量的私有化。
        inner(); // 2
