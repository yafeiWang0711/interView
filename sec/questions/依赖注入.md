### 依赖注入
    vue 中使用依赖注入机制，实现组件之间的通信。 依赖注入是一种父子组件之间的通信方式，允许祖先组件向其所有后代组件提供数据。 依赖注入的实现原理是： 父组件通过 provide 选项提供数据，子组件通过 inject 选项注入数据。
    可以不通过 props 传递数据，而是直接在组件树中注入所需的数据。

    父组件（或祖先组件） 通过 provide 提供数据。
    子组件（或后代组件） 通过 inject 注入并使用这些数据。

    依赖注入机制的实现：
        1. 父组件使用 provide 选项提供数据。
        2. 子组件使用 inject 选项注入数据。
        3. 子组件可以直接使用注入的数据，而不需要通过 props 传递。
        4. 子组件可以使用注入的数据进行计算或渲染。

        例如，父组件提供数据：
        parent.vue
        ```
        provide() {
            return {
                name: 'vue',
                age: 20
            }
        }
        ```

        子组件注入数据：
        child.vue
        ```
        inject: ['name', 'age']
        ```
        子组件可以直接使用注入的数据：
        ```
        console.log(this.name); // 'vue'
        console.log(this.age); // 20
        ```
