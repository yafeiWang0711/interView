### 搜索引擎优化
    搜索引擎优化（Search Engine Optimization，SEO）是指通过优化网站的内容、结构和技术，提高网站在搜索引擎中的排名，从而增加网站的流量和流量来源。
    SEO的目的是让网站在搜索引擎中获得更好的排名，从而获得更多的流量和用户。
    SEO的优化方法有很多，但大体上可以分为两类：一类是内部优化，另一类是外部优化。
    SEO主要包括以下几个方面：
        1. 关键词优化：选择合适的关键词，并将其合理地分布在网站的标题、描述、内容中。
        2. 页面结构优化：优化网站的页面结构，如使用语义化的 HTML 标签、优化页面标题、优化页面描述等。
        3. 外部链接优化：优化网站的外部链接，如使用外部链接的页面数量、外部链接的质量等。
        4. 技术优化：优化网站的技术，如使用 HTTPS 协议、优化网站的加载速度、优化网站的响应时间等。
        5. 内容优化：优化网站的内容，如使用有价值的内容、优化内容的质量、优化内容的更新频率等。

    html 相比 vue 来说，更适合做 SEO。这是因为 HTML 是搜索引擎可以直接读取的格式，而 Vue 是一种前端框架，它的内容需要通过 JavaScript 来渲染，因此搜索引擎无法直接读取其内容。
    而 HTML 是一种静态的标记语言，它的内容是固定的，而 Vue 是一种动态的框架，它的内容是根据用户的操作和数据的变化而变化的。
    因此，HTML 更适合做 SEO，而 Vue 更适合做交互性的网站。
    但是，HTML 也有一些缺点，如内容更新不及时、用户体验差等。
    因此，在开发网站时，需要根据网站的性质和目标受众，选择合适的技术和工具。

    从技术层面，深度 SEO 优化可从以下方面进行：
    页面结构优化：使用语义化标签（如 header、nav、article、section 等），合理组织页面结构，使搜索引擎更好地理解页面内容。
    元数据优化：设置合适的 title、description、keywords 等 meta 标签，准确描述页面内容。
    内容优化：确保内容原创、高质量、与关键词相关，合理使用标题标签（h1-h6），并包含关键词。
    链接优化：优化内部链接结构，确保页面之间的链接清晰、合理；获取高质量的外部链接，提升页面权重。
    性能优化：提高页面加载速度（如代码压缩、图片优化、使用缓存等），因为页面加载速度是搜索引擎排名的一个因素。
    移动端优化：确保页面在移动端有良好的展示和体验，适配移动端设备。
    结构化数据（Schema）：添加结构化数据，帮助搜索引擎更好地理解页面内容，可能在搜索结果中展示更丰富的信息（如评分、价格、事件等）。
    ** canonical 标签 **：处理重复内容，通过 canonical 标签指定首选的页面版本，避免搜索引擎将重复内容视为低质量内容。
