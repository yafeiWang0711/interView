2.  什么是变量提升？函数提升和变量提升有什么优先级？
    函数提升：在代码执行之前，JavaScript 引擎会将所有的函数声明（function declaration）提升至当前作用域的顶部。
    变量提升：在代码执行之前，JavaScript 引擎会将所有的变量声明（var、let、const）提升至当前作用域的顶部。
    函数提升的优先级高于变量提升。

3.  解释一下 JavaScript 中的数据类型，以及基本数据类型和引用数据类型的区别。
    基本数据类型：String、Number、Boolean、null、undefined、Symbol（es6新增）、BigInt（es10新增）
    引用数据类型：Object、Function、Array、RexExp、Date
    基本数据类型：栈内存存储，占用空间固定，大小已知，值不可变
    引用数据类型：堆内存存储，占用空间不固定，大小未知，值可变
    基本数据类型的变量存储的是值本身，而引用数据类型的变量存储的是指向对象的地址。
    基本数据类型的变量是不可变的，而引用数据类型的变量是可变的。
    基本数据类型的变量可以直接赋值，而引用数据类型的变量需要使用 new 关键字创建对象。

5.  null 和 undefined 的区别是什么？在什么情况下会出现？
    null 表示一个空值，表示没有任何东西。
    undefined 表示一个未定义的值，表示变量没有被赋值。
    null 通常出现在以下几种情况下：
    1.  当一个变量被赋值为 null 时，表示该变量的值已经被清空。
    2.  当一个函数返回了一个空值时，会返回 null。
    3.  当一个对象的属性没有被赋值时，默认值是 null。
    4.  当一个函数的参数没有被传递时，默认值是 undefined。
    5.  当使用 new 关键字创建一个对象时，如果没有返回值，默认返回 null。
    6.  当使用 new 关键字创建一个对象时，如果返回了一个对象，默认返回该对象。

    4.  当一个变量没有被赋值时，默认值是 undefined，而 undefined 不是数字，所以会返回 NaN。例如：let a; console.log(a); 会返回 NaN。

8.  什么是闭包？闭包有哪些应用场景，可能会带来什么问题？
    闭包是指在一个函数内部创建一个函数，该内部函数可以访问到外部函数的变量。
    闭包是一种强大的功能，它可以让我们在函数外部访问到函数内部的变量。
    闭包是实现防抖节流的关键，通过闭包保存变量状态，避免全局变量污染
    问题：闭包会占用内存，如果使用不当会导致内存泄漏。
    解决：
        1. 及时释放闭包：在不需要闭包的地方，及时将闭包赋值为 null，释放内存。
        2. 避免循环引用：循环引用会导致内存泄漏，需要避免循环引用的情况。
        3. 避免闭包嵌套：闭包嵌套会导致内存泄漏，需要避免闭包嵌套的情况。
        4. 避免闭包占用内存：闭包占用的内存会一直存在，直到闭包被释放。所以，在不需要闭包的地方，及时将闭包赋值为 null，释放内存。


9.  什么是 this？在不同场景下 this 的指向有什么不同？
    this 指向的是当前执行上下文的函数，在不同的场景下 this 的指向不同。
    1.  全局作用域下：this 指向全局对象（浏览器下是 window 对象）
    2.  函数作用域下：this 指向调用函数的对象
    3.  构造函数作用域下：this 指向新创建的对象
    4.  箭头函数作用域下：this 指向定义时的对象，而不是调用时的对象
    5.  事件绑定下：this 指向绑定事件的对象
    6.  定时器下：this 指向全局对象（浏览器下是 window 对象）

1.  什么是原型？什么是原型链？原型链的作用是什么？
    prototype：原型是 JavaScript 中实现继承的一种机制，它允许一个对象可以拥有另一个对象的属性和方法。
    原型：原型是 JavaScript 中实现继承的一种机制，它允许一个对象可以拥有另一个对象的属性和方法。
    原型链：原型链是 JavaScript 中实现继承的一种机制，它允许一个对象可以拥有另一个对象的属性和方法。
    原型链的作用：实现继承，子类可以继承父类的属性和方法。
    原型链的实现：每个对象都有一个 __proto__ 属性，指向它的原型对象，形成一个链式结构。
    原型链的查找：当访问一个对象的属性或方法时，会先查找对象本身是否有该属性或方法，如果没有，则会查找它的原型对象是否有该属性或方法，依次类推，直到找到 Object.prototype 为止。
    原型链的问题：
        1.  性能问题：查找原型链上的属性或方法需要遍历整个原型链，性能较低。
        2.  循环引用问题：如果原型链中存在循环引用，会导致内存泄漏。
        3.  继承问题：原型链只能实现单继承，不能实现多继承。
    原型与原型链（prototype/__proto__的关系，继承实现） 
    原型：每个对象都有一个 __proto__ 属性，指向它的原型对象。
    原型链：每个对象的 __proto__ 属性指向它的原型对象，形成一个链式结构。
    继承实现：子类的原型对象指向父类的原型对象，从而实现继承。

6.  什么是防抖和节流？它们的应用场景是什么？如何实现？
    防抖：在事件触发后，等待一段时间在执行，如果在n秒内再次触发事件，则重新等待n秒。
    节流：在事件触发后，等待一段时间在执行，如果在n秒内再次触发事件，则不执行。相当于一直点击，n秒内只执行一次。
    应用场景：
        防抖：搜索框输入内容后，等待用户输入完成后再执行搜索。
        节流：滚动事件，只执行一次。
        点击事件：防止用户重复点击。

    手写防抖
    function debounce(fn,delay){
        let timer = null;
        return function(){
            if(timer){
                clearTimeout(timer);
            }
            timer = setTimeout(()=>{
                fn.apply(this,arguments);
            },delay);
            // 调用时返回this
            return this;
        }
    }    

    手写节流
    function throttle(fn,delay){
        let timer = null;
        return function(){
            if(timer){
                return;
            }
            timer = setTimeout(()=>{
                fn.apply(this,arguments);
                timer = null;
            },delay);
        }
    }

8.  宏任务和微任务有什么区别？分别包括哪些？
    宏任务：宏任务是指在事件循环中执行的任务，例如 setTimeout、setInterval、setImmediate、I/O 操作、UI 渲染等。
    微任务：微任务是指在当前宏任务执行完成后立即执行的任务，例如 Promise、MutationObserver 等。
    区别：
        1.  执行时机：宏任务在事件循环的每个宏任务执行完成后，在当前宏任务的末尾执行一次；而微任务在每个宏任务的开始阶段和结束阶段都执行，而微任务在当前宏任务执行完成后立即执行。
        2.  执行顺序：微任务的执行顺序优先于宏任务。
        3.  执行次数：宏任务可以执行多次，而微任务只能执行一次。
    事件循环的流程：
        1· 执行同步代码（属于当前宏任务的一部分）。
        2· 同步代码执行完毕后，检查微任务队列：
        3. 若有微任务，按顺序全部执行完毕（包括执行微任务过程中新增的微任务）。
        4. 若无微任务，进入下一步。
        5. 执行UI 渲染（可选，浏览器可能会合并多次渲染）。
        6. 从宏任务队列中取一个任务执行，回到步骤 1，重复循环。

        // 同步代码（属于第一个宏任务）
        console.log('1');
        // 宏任务：setTimeout
        setTimeout(() => {
        console.log('2');
        // 微任务：Promise.then
        Promise.resolve().then(() => console.log('3'));
        }, 0);
        // 微任务：Promise.then
        Promise.resolve().then(() => {
        console.log('4');
        // 宏任务：嵌套的setTimeout
        setTimeout(() => console.log('5'), 0);
        });
        // 同步代码
        console.log('6');

        执行结果：1 → 6 → 4 → 2 → 3 → 5


9.  什么是 Promise？它解决了什么问题？Promise 有哪些状态？
    Promise 是一种异步编程解决方案，它解决了回调地狱的问题。
    它有三种状态：
    1.  pending：初始状态，不是成功或失败。
    2.  fulfilled：意味着操作成功完成。
    3.  rejected：意味着操作失败。



10. Promise 的常用方法有哪些？all、race、allSettled、any 有什么区别？
    Promise 的常用方法有：
    1.  then：当 Promise 状态变为 fulfilled 时调用。
    2.  catch：当 Promise 状态变为 rejected 时调用。
    3.  finally：无论 Promise 状态如何，都会调用。
    4.  all: 返回一个 Promise，只有当所有给定的 Promises 都成功时才解决。
    5.  race: 返回一个 Promise，只要给定的 Promises 中有一个解决或拒绝，它就解决或拒绝。
    6.  allSettled: 返回一个 Promise，只有当所有给定的 Promises 都解决或拒绝时才解决。
    7.  any: 返回一个 Promise，只要给定的 Promises 中有一个成功，它就成功。如果所有 Promises 都拒绝，它会拒绝并返回一个 AggregateError。

5.  什么是浅拷贝和深拷贝？如何实现对象的深拷贝？
    浅拷贝：只复制对象的第一层属性，如果对象的值是引用类型，则只会复制引用的地址。
    深拷贝：递归复制对象的所有属性，包括引用类型的属性。
    实现对象的深拷贝可以使用 JSON.parse(JSON.stringify(obj)) 方法，但是该方法有一些局限性，如不能复制函数、不能复制循环引用等。
    可以使用递归实现深拷贝，或者使用第三方库如 lodash 中的 cloneDeep 方法。
    // 递归实现深拷贝
    function deepClone(obj) {
        if (obj === null || typeof obj !== 'object') {
            return obj;
        }
        // 处理循环引用
        if (obj instanceof Date) {
            return new Date(obj);
        }
        if (obj instanceof RegExp) {
            return new RegExp(obj);
        }
        let clone = Array.isArray(obj) ? [] : {};
        for (let key in obj) {
            if (obj.hasOwnProperty(key)) {
                clone[key] = deepClone(obj[key]);
            }
        }
        return clone;
    }
