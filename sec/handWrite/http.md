### 网络安全



1.  什么是跨站脚本攻击（XSS）？如何防范 XSS 攻击？
    跨站脚本攻击（XSS）是一种攻击技术，攻击者通过在网页中注入恶意脚本，从而获取用户的敏感信息或控制用户的浏览器。
    防范 XSS 攻击的方法有以下几种：
    1.  对用户输入进行过滤和转义，例如使用 encodeURIComponent() 或 escape() 函数对用户输入进行编码，或者使用正则表达式对用户输入进行过滤。
    2.  对输出到网页的内容进行编码，例如使用 encodeURIComponent() 或 escape() 函数对输出的内容进行编码，或者使用正则表达式对输出的内容进行过滤。
    3.  使用 HTTP Only 标志对 Cookie 进行设置，防止 Cookie 被 JavaScript 访问。
    4.  使用 Content Security Policy（CSP）对网页进行限制，防止恶意脚本的注入。
    5.  使用验证码或人机验证来防止自动化脚本的攻击。

2.  什么是跨站请求伪造（CSRF）？如何防范 CSRF 攻击？
    跨站请求伪造（CSRF）是一种攻击技术，攻击者通过在用户不知情的情况下，利用用户的身份信息向服务器发送恶意请求。
    防范 CSRF 攻击的方法有以下几种：
    1.  使用 CSRF 令牌（CSRF Token）来验证请求的合法性。
    2.  在请求头中添加自定义的字段，例如 X-CSRF-Token，来验证请求的合法性。
    3.  使用 SameSite 属性来限制 Cookie 的发送范围，防止 Cookie 被跨站请求利用。
    4.  对用户输入进行过滤和转义，例如使用 encodeURIComponent() 或 escape() 函数对用户输入进行编码，或者使用正则表达式对用户输入进行过滤。
    5.  对服务器端的代码进行安全编码，例如使用参数化查询、 PreparedStatement 等技术，防止 SQL 注入攻击。
