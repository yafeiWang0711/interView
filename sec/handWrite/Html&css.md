# 前端 HTML 与 CSS 面试题汇总

## HTML 部分

1. 什么是 HTML？它的基本结构是什么？
   html是一种用于创建网页的标准标记语言，它由一系列的标签（tags）组成。
   每个标签都有特定的含义和作用，用于定义网页的结构和内容。
   html的基本结构包括文档类型声明（DOCTYPE）、html标签、head标签和body标签。
   文档类型声明用于告诉浏览器当前的文档类型是什么，以便浏览器正确地解析和渲染页面。
   html标签是根标签，所有的其他标签都嵌套在html标签中。
   head标签用于包含网页的元数据（如标题、字符集、样式表和脚本）。
   body标签用于包含网页的可见内容（如文本、图像、视频和音频）。
2. DOCTYPE 的作用是什么？HTML5 的 DOCTYPE 声明方式是什么？
   DOCTYPE是为了告诉浏览器当前的文档类型是什么，以便浏览器正确地解析和渲染页面。
   HTML5 的 DOCTYPE 声明方式是：<!DOCTYPE html>
3. HTML5 与 HTML4 的主要区别有哪些？
4. 语义化标签的意义是什么？列举 5 个 HTML5 新增的语义化标签并说明其用途。
   语义化标签的意义是为了增强网页内容的可读性和可维护性。
   HTML5 新增的语义化标签包括：
   header：定义文档的头部区域，通常包含网站的标志、导航链接等
   footer：定义文档的底部区域，通常包含版权信息、联系方式等
   main：定义文档的主要内容区域，通常包含页面的主体部分
   sidebar：定义文档的侧边栏区域，通常包含导航链接、广告等
   article：定义文档的独立内容区域，通常包含一篇文章或新闻等
   section：定义文档的节区域，通常包含一个主题或章节等
   aside：定义文档的侧边栏区域，通常包含与主要内容相关的内容（如侧边栏、广告等）
   figure：定义文档的独立内容区域，通常包含一张图片或图表等
   figcaption：定义文档的独立内容区域，通常包含图片或图表的标题等
   mark：定义文档的独立内容区域，通常包含被标记的文本等
   time：定义文档的独立内容区域，通常包含时间信息等
5. `<div>` 和 `<span>` 的区别是什么？分别适用于什么场景？
   div是一个块级元素，常用于包含其他元素用于结构化布局
   span是一个行内元素，常用来包裹文本或行内元素，用于样式化文本或行内元素
6. `<img>` 标签的 `alt` 属性有什么作用？
    imgb标签中的alt属性是当图片无法展示时显示的文本，用于提高网页的可访问性。
7. `<a>` 标签的 `href` 和 `target` 属性分别有什么作用？`target="_blank"` 有什么安全风险？
    href属性指定跳转的目标地址，target属性指定打开链接的目标窗口或框架。
    target="_blank"表示在新窗口或新标签页中打开链接，这可能会导致安全风险，因为新窗口可以访问原始窗口的文档对象模型（DOM），从而可能导致跨站脚本攻击（XSS）。
    为了避免安全风险，建议在打开链接时使用target="_self"或target="_parent"，或者在服务器端对链接进行验证和过滤。

11. `<input>` 标签的 `readonly` 和 `disabled` 属性有什么区别？
    readonly属性表示输入框只读，用户可以查看但不能修改
    disabled属性表示输入框禁用，用户不能查看也不能修改
    readonly属性不会阻止表单提交，而disabled属性会阻止表单提交
    readonly属性可以保留表单数据，而disabled属性不会保留表单数据

13. 什么是 Canvas？它与 SVG 有什么区别？
    Canvas是一种基于 HTML5 的绘图技术，允许在网页上绘制图形和图像。
    它是一个二维绘图上下文，通过 JavaScript 代码绘制图形和图像。
    Canvas 与 SVG 不同，SVG 是基于 XML 的矢量图形格式，而 Canvas 是基于像素的位图格式。
    因此，Canvas 绘制的图形和图像在缩放时会失真，而 SVG 绘制的图形和图像在缩放时不会失真。
    另外，Canvas 绘制的图形和图像可以通过 JavaScript 代码动态修改，而 SVG 绘制的图形和图像不能动态修改。

## CSS 基础

21. CSS 的全称是什么？它的作用是什么？
    CSS 的全称是 Cascading Style Sheets，中文名为层叠样式表。
    它的作用是为了描述 HTML 文档的样式，使 HTML 文档看起来更加美观和易读。
22. CSS 的三种引入方式是什么？各自的优缺点是什么？
    内联样式
    内部样式表
    外部样式表
    内联样式：在 HTML 元素的 style 属性中直接编写 CSS 代码。
    内部样式表：在 HTML 文档的 head 元素中使用 style 标签编写 CSS 代码。
    外部样式表：将 CSS 代码编写在一个独立的 .css 文件中，然后在 HTML 文档中使用 link 标签引入。
    内联样式：优点是简单易用，缺点是不利于代码复用和维护。
    内部样式表：优点是方便编写和维护，缺点是只能在当前文档中使用。
    外部样式表：优点是方便复用和维护，缺点是需要引入额外的文件。
