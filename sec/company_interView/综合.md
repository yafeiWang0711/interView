    function deepClone(obj, hash = new WeakMap()) {
        if (obj === null || typeof obj !== 'object') {
            return obj
        }
        if (hash.has(obj)) return hash.get(obj)
        let cloneObj = new obj.constructor()
        hash.set(obj, cloneObj)
        for (let key in obj) {
            if (obj.hasOwnProperty(key)) {
                cloneObj[key] = deepClone(obj[key], hash)
            }
        }
        return cloneObj
    }

### 2. Promise.all 和 Promise.allSettled 的区别
    1. Promise.all 会等待所有 Promise 都成功才返回结果，只要有一个 Promise 失败，就会立即返回失败结果。
    2. Promise.allSettled 会等待所有 Promise 都 settled（无论成功还是失败）才返回结果，不会立即返回失败结果。
    3. Promise.all 只返回成功的结果，Promise.allSettled 返回每个 Promise 的结果（包括失败的原因）。

### 3. 请解释浏览器中的宏任务和微任务
    1. 宏任务（MacroTask）：
    宏任务是指在浏览器环境中，每次事件循环（Event Loop）执行的任务。每个宏任务之间是独立的，不会被其他任务中断。常见的宏任务包括 setTimeout、setInterval、I/O 操作、UI 渲染等。
    2. 微任务（MicroTask）：
    微任务是指在浏览器环境中，每次事件循环（Event Loop）执行的任务。与宏任务不同，微任务会在当前宏任务执行完成后立即执行，不会被其他任务中断。常见的微任务包括 Promise 的回调、MutationObserver 回调等。
    3. 执行顺序：
    每个宏任务执行完成后，会检查是否有微任务需要执行。如果有，会将所有微任务依次执行完毕，然后再执行下一个宏任务。这个过程会一直重复，直到所有宏任务和微任务都执行完毕。
    4. 微任务和宏任务的优先级：
    微任务的优先级要高于宏任务。这意味着，在每个宏任务执行完成后，会立即执行所有微任务，而不会被其他任务中断。

### 4. 实现一个函数，每隔一秒打印一次数字，从 1 开始，需要考虑闭包问题
    function printNumber() {
        let i = 1
        setInterval(() => {
            console.log(i++)
        }, 1000)
    }
    printNumber()
    这段代码存在闭包问题，因为每次 setInterval 都会创建一个新的作用域，导致 i 的值不会被正确地更新。

    解决方法：
    1. 使用 let 声明 i，因为 let 声明的变量会绑定到块级作用域，不会被提升到全局作用域。
    2. 使用闭包，将 i 封装在一个函数中，避免被外部访问和修改。

### 6. Tree shaking 是什么？
    Tree shaking 是一种代码优化技术，它可以在打包时分析代码，将没有被使用的代码从最终的打包文件中移除，从而减少文件大小。
    1. 什么是 Tree shaking？
    Tree shaking 是一种代码优化技术，它可以在打包时分析代码，将没有被使用的代码从最终的打包文件中移除，从而减少文件大小。
    2. Tree shaking 的工作原理
    Tree shaking 基于 ES6 模块的静态分析，通过判断模块是否被引用，来确定是否需要保留该模块的代码。如果模块没有被引用，就会被移除。
    3. Tree shaking 的优势
    Tree shaking 可以减少最终打包文件的大小，从而提高页面加载速度。
    4. Tree shaking 的限制
    Tree shaking 只能移除没有被引用的代码，不能移除被引用的代码中没有被使用的部分。
    5. Tree shaking 的使用场景
    Tree shaking 适用于使用 ES6 模块的项目，因为它基于静态分析，所以只能移除没有被引用的代码。
    6. Tree shaking 的实现方式
    Tree shaking 可以通过 webpack 等打包工具实现，也可以通过 babel 等转译工具实现。

### 7. 防抖和节流的应用场景
    1. 防抖：
    防抖是指在事件触发后，等待一段时间再执行回调函数。如果在等待时间内事件再次触发，就会重新等待。
    防抖的应用场景包括：
    输入框实时搜索：用户在输入框中输入内容时，会实时触发搜索事件，但是搜索事件的频率会非常高。使用防抖可以避免频繁触发搜索事件，提高搜索效率。
    滚动事件：在滚动页面时，会频繁触发滚动事件。使用防抖可以避免频繁执行回调函数，提高性能。
    2. 节流：
    节流是指在事件触发后，在一定时间内只执行一次回调函数。如果在等待时间内事件再次触发，也不会重新执行。
    节流的应用场景包括：
    鼠标移动事件：在鼠标移动时，会频繁触发移动事件。使用节流可以避免频繁执行回调函数，提高性能。
    窗口resize事件：在窗口resize时，会频繁触发resize事件。使用节流可以避免频繁执行回调函数，提高性能。
    3. 防抖和节流的区别：
    防抖是指在事件触发后，等待一段时间再执行回调函数。如果在等待时间内事件再次触发，就会重新等待。
    节流是指在事件触发后，在一定时间内只执行一次回调函数。如果在等待时间内事件再次触发，也不会重新执行。
    4. 防抖和节流的实现方式：
    防抖可以通过 setTimeout 实现，节流可以通过 setInterval 实现。
    5. 防抖和节流的使用场景：
    防抖适用于输入框实时搜索、滚动事件等场景。
    节流适用于鼠标移动事件、窗口resize事件等场景。

### 8. 平时做过什么性能优化的工作？
    1. 代码拆分：
    代码拆分是指将代码拆分成多个模块，每个模块只负责一部分功能。这样可以减少每个模块的代码量，从而提高加载速度。
    2. 图片压缩：
    图片压缩是指将图片压缩成更小的体积，从而减少图片的加载时间。
    3. 缓存策略：
    缓存策略是指将一些静态资源缓存到浏览器中，避免重复请求。
    4. 减少 HTTP 请求：
    减少 HTTP 请求是指减少页面加载时需要发送的 HTTP 请求次数。可以通过合并文件、使用 CDN 等方式减少 HTTP 请求。
    5. 懒加载：
    懒加载是指在需要的时候才加载资源，而不是在页面加载时就加载所有资源。可以通过按需加载、代码分割等方式实现懒加载。
    6. 预加载：
    预加载是指在页面加载时就预先加载一些资源，避免在需要时再请求。可以通过预加载图片、字体、脚本等方式实现预加载。
    7. 资源压缩：
    资源压缩是指将资源压缩成更小的体积，从而减少资源的加载时间。可以通过压缩图片、压缩字体、压缩脚本等方式实现资源压缩。

### 9. CDN的原理以及使用场景
    1. 原理：
    CDN的原理是将静态资源分布到多个服务器上，当用户请求资源时，会根据用户的位置选择最近的服务器返回资源。
    2. 使用场景：
    CDN适用于静态资源的分发，比如图片、字体、脚本、样式表等。
    3. 优势：
    CDN可以提高资源的加载速度，减少资源的加载时间。
    4. 劣势：
    CDN会增加服务器的负载，因为每个用户请求都需要从不同的服务器返回资源。
    5. 解决方法：
    可以通过设置缓存策略，将静态资源缓存到用户的本地，避免重复请求。

### 11. node 中间件
    Node.js 中间件是一种在 Node.js 应用程序中执行特定任务的函数。中间件可以用于处理请求、响应、错误等任务。
    1. 什么是 Node.js 中间件？
    Node.js 中间件是一种在 Node.js 应用程序中执行特定任务的函数。中间件可以用于处理请求、响应、错误等任务。
    2. 如何使用 Node.js 中间件？
    可以使用 express 或 koa 等框架来创建和使用中间件。
    3. 中间件的执行顺序：
    中间件的执行顺序是由中间件的注册顺序决定的，先注册的中间件会先执行。
    4. 中间件的类型：
    中间件可以分为多种类型，包括请求中间件、响应中间件、错误处理中间件等。
    5. 中间件的应用场景：
    中间件适用于处理请求、响应、错误等任务，可以提高代码的可维护性和可读性。

    中间件的原理
    中间件的原理是基于 Node.js 的事件循环机制。当请求到达服务器时，会触发一个事件，然后按照注册的顺序执行每个中间件函数，直到处理完所有任务并返回响应。

    function insertionSort(arr) {
        for (let i = 1; i < arr.length; i++) {
            let j = i - 1
            let temp = arr[i]
            while (j >= 0 && arr[j] > temp) {
                arr[j + 1] = arr[j]
                j--
            }
            arr[j + 1] = temp
        }
        return arr
    }
