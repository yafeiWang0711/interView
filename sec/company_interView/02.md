### 1. 虚拟DOM的概念
    虚拟DOM是js中一种轻量级的对象，用于描述真实DOM的结构和属性。它是一种在内存中构建的树状结构，用以模拟真实的DOM节点。
    虚拟DOM的优势：
        1. 减少了对真实DOM的操作次数，提高了性能
        2. 跨平台性强，可以在不同的平台上运行，如浏览器、移动端、服务器端等
        3. 简化了开发流程，开发人员可以专注于业务逻辑，而不需要关注底层的DOM操作
    虚拟DOM的工作原理：
        1. 当组件的状态发生变化时，会触发重新渲染
        2. 重新渲染时，会根据新的状态生成新的虚拟DOM树
        3. 虚拟DOM树会与旧的虚拟DOM树进行对比，找出差异
        4. 差异会被应用到真实DOM上，从而更新视图

        虚拟DOM的实现方式：
            1. 基于JavaScript对象实现
            2. 基于XML实现
            3. 基于JSON实现
            4. 基于其他数据结构实现

### 2. diff算法
    diff算法是一种用于比较两个虚拟DOM树的算法，它可以找出两个树之间的差异。
    diff算法的工作原理：
        1. 对两个树进行深度优先遍历，同时比较每个节点的类型和属性
        2. 如果节点类型不同，直接将新节点替换旧节点
        3. 如果节点类型相同，比较节点的属性，将不同的属性更新到真实DOM上
        4. 递归比较子节点，重复以上步骤

### 4. 图片懒加载的方法
    图片懒加载是一种延迟加载图片的技术，它可以提高页面的加载速度和性能。
    图片懒加载的方法：
        1. 监听图片是否进入视口
        2. 当图片进入视口时，加载图片
        3. 可以使用 IntersectionObserver 来监听图片是否进入视口
        4. 可以使用 srcset 属性来实现响应式图片
        5. 可以使用 loading="lazy" 属性来实现图片懒加载
        6. 可以使用第三方库来实现图片懒加载，如 lazyload、lozad 等


### 5. ref绑定能不能直接调用子组件的值和属性
    ref可以绑定到子组件上，但不能直接调用子组件的值和属性。
    如果要调用子组件的值和属性，可以使用以下方法：
        1. 子组件定义一个方法，用于返回值或属性
        2. 父组件通过 ref 绑定子组件，然后调用子组件的方法来获取值或属性
        3. 可以使用 $refs 来获取子组件的实例，然后调用子组件的方法来获取值或属性
        4. 可以使用 $refs 来获取子组件的实例，然后直接访问子组件的属性或方法，如 $refs.childComponent.method()
        vue3 需要子组件使用defineExpose来暴露属性或方法，父组件才能访问到子组件的属性和方法
        例如：
            子组件：
            <script setup>
            import { ref } from 'vue'
            const count = ref(0)
            function increment() {
                count.value++
            }
            defineExpose({
                count,
                increment
            })
            </script>
            父组件：
            <template>
            <div>
                <ChildComponent ref="childComponent" />
                <button @click="handleClick">调用子组件方法</button>
            </div>
            </template>
            <script setup>
            import { ref } from 'vue'
            import ChildComponent from './ChildComponent.vue'
            const childComponent = ref(null)

### 6. 插槽slot
    插槽是一种用于在组件中插入自定义内容的机制。它可以在组件的模板中定义一个插槽，然后在使用组件时，通过插槽插入自定义内容。
    插槽的工作原理：
        1. 组件的模板中定义一个插槽，使用 <slot> 标签来表示
        2. 在使用组件时，通过插槽插入自定义内容
        3. 自定义内容会替换组件模板中的插槽位置
    插槽的类型：
        1. 匿名插槽
            slot标签没有name属性，默认插槽，只能有一个匿名插槽
        2. 具名插槽
            slot标签有name属性，可以有多个具名插槽，每个插槽都有一个唯一的名称
            在父组件中使用v-slot指令来指定插槽的名称，并传递数据给子组件
            在子组件中使用<slot>标签，并指定插槽的名称和传递的数据，如
            <slot name="slotName" :data="data"></slot>
            父组件中可以使用v-slot指令来指定插槽的名称，并传递数据给子组件，如
            <template v-slot:slotName="slotProps"></template>

        3. 作用域插槽
            作用域插槽是一种特殊的具名插槽，它可以将子组件的数据传递给父组件
            在子组件中使用<slot>标签，并指定插槽的名称和传递的数据，如
            <slot name="slotName" :data="data"></slot>
            父组件中可以使用v-slot指令来指定插槽的名称，并传递数据给子组件，如
            <template v-slot:slotName="slotProps">
                {{ slotProps.data }}
            </template>
            作用域插槽的工作原理：
                1. 子组件中使用<slot>标签，并指定插槽的名称和传递的数据
                2. 父组件中使用v-slot指令来指定插槽的名称，并传递数据给子组件
                3. 子组件中的数据会被传递给父组件中的插槽，父组件可以使用插槽中的数据来渲染自定义内容

### 8. 文件上传怎么做，切片上传
    文件上传可以使用HTML5的File API来实现，切片上传可以使用File API的slice方法来实现。
    例如：
        var file = document.getElementById('file').files[0];
        var slice = file.slice(0, 1024 * 1024);
        var formData = new FormData();
        formData.append('file', slice);
    
    切片上传的工作原理：
        1. 将文件切割成多个小块
        2. 每个小块都上传到服务器
        3. 服务器收到所有小块后，将它们合并成一个完整的文件
        4. 服务器处理完文件后，返回上传结果，如上传成功、上传失败等
        5. 客户端收到上传结果后，根据结果进行处理，如显示上传成功、上传失败等
        6. 客户端可以使用进度条来显示上传进度
        7. 客户端可以使用取消上传按钮来取消上传

### 9. v-for和v-if的优先级
        在vue2中，v-for的优先级高于v-if。
        这意味着，在使用v-for循环渲染列表时，v-if会被应用到每个列表项上，而不是整个列表。
        例如：
            <div v-for="item in list" v-if="item.visible">
                {{ item.name }}
            </div>
        在这个例子中，只有当item.visible为true时，才会渲染列表项。
        而在vue3中，v-if的优先级高于v-for。
        这意味着，在使用v-if条件渲染时，v-for会被应用到整个列表上，而不是每个列表项上。
        例如：
            <div v-if="list.length > 0">
                <div v-for="item in list">
                    {{ item.name }}
                </div>
            </div>
        在这个例子中，只有当list的长度大于0时，才会渲染列表项。
